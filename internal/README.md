# Internal documents (not published)

These pages used to be built into the public website at /sop/ and
/events/. They now live outside `src/`, so Eleventy no longer builds or
deploys them.

- `sop/` — the operating manual (layouts in `_includes/layouts/sop*.njk`)
- `events.njk` with `_data/events.js` — the marketing calendar

Note: this repository is public on GitHub, so these files are still
readable there. Make the repository private, or move this folder to a
private repository, to keep them private.
